## Submission Checklist (per directory)

For each directory, ensure:
- [ ] Business name matches EXACTLY (JHB Curtain Cleaning)
- [ ] Address matches EXACTLY (10 2nd Ave, Florida, Roodepoort, 1710)
- [ ] Phone matches EXACTLY (+27 75 011 9200)
- [ ] Website URL is correct (https://jhbcurtaincleaning.co.za)
- [ ] Categories include "Dry Cleaner" or "Curtain Cleaning"
- [ ] Business description is consistent (use the standard description above)
- [ ] Operating hours are correct
- [ ] Photos uploaded (logo, hero, before/after)
- [ ] Listing is verified (if verification is offered)
- [ ] Listing URL is recorded (for schema `sameAs` updates)

## Monitoring Citations

After submission, check monthly:
1. All citations are still live (visit each URL)
2. NAP is still consistent (no address/phone changes)
3. New reviews are responded to
4. No duplicate listings have been created

Use a tool like **BrightLocal** or ** Whitespark** for automated citation monitoring (paid).
